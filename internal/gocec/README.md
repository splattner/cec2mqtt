# gocec

Go bindings for [libcec](https://github.com/Pulse-Eight/libcec), used by cec2mqtt to talk to the CEC adapter.

This package was written by [Robert Meijers](https://github.com/RobertMe), the original author of cec2mqtt, and copied
from [RobertMe/gocec](https://github.com/RobertMe/gocec) at commit
[a674c11](https://github.com/RobertMe/gocec/commit/a674c1177b80) (2021-12-21), the version cec2mqtt used until then.
It's maintained here since, as the original repository isn't developed any further. The changes are in the git history
of this directory.
